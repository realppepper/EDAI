# EDAI — 아날로그 IC 설계 자동화 및 피드백 시스템

## 프로젝트 개요

사용자가 요구하는 아날로그 회로를 AI가 설계하고, EDA 시뮬레이션으로 동작과 성능을 검사한 뒤 결과를 바탕으로 수정을 반복하는 시스템을 목표로 합니다. 현재 개발·평가 대상은 **op amp**입니다.

이 브랜치는 다훈이 진행한 **데이터시트 사양 추출·검사 계획·설계/검증 루프·고정 하네스·실행 안정화** 작업을 공유합니다. 동일한 모델에서 설계 지침과 피드백 구조가 실제 성능에 도움이 되는지도 비교하려고 합니다. 추가 지침의 효과는 아직 입증하지 못했습니다.

프로젝트 코드는 `EDAI_OpAmp_Rebuild/` 폴더에 있습니다. 아래 파일·폴더 설명은 해당 폴더를 기준으로 합니다. 기준일: 2026-11-15.

## 현재 흐름

```text
PDF 전체 탐색 → 후보 페이지 → 이미지·Nemotron 파싱 → 파싱 검사
 → 코드가 사양 행 생성 → LLM 의미 주석·원문 대조
 → HKG / PDG → 목표 선택·검사 계획
 → 고정 설계 지침 + 설계자 입력
 → 회로 넷리스트 → LTspice 검사 → 결과 피드백 → 회로 수정
 → 최선 후보·검증 이력 저장 / 중단 후 같은 후보 재개
```

**완전 무인 LLM 서비스는 아닙니다.** Nemotron Parse 호출은 구현돼 있지만, 사양 의미 검토·PDG 주석·회로 수정 제안은 현재 채팅 AI가 JSON 파일로 전달하는 경로를 사용합니다. 설계 모델을 호출하는 API 전송과 자동 모델 전환은 아직 연결하지 않았습니다.

## 확인한 결과

- LM358B 참고 사양: 42행을 관리하고 프로젝트 범위로 선택한 32행을 80개 검사 조건으로 추적합니다.
- 기존 18pF 회로의 엄격한 재검증: **58조건 통과 / 22조건 미검증**. 일반 MOS 모델·1채널·25°C·유한 표본 기준입니다.
- 입력 범위 검사는 계산 지점 누락을 검출하며, 3/5/15/36V 각각 원래 201개 지점을 확인했습니다.
- 파일 잠금 재시도, 같은 후보 검증 재개, 최선 후보·보고서 복구를 확인했습니다.
- 원래 작업 환경: 코드 테스트 192개 통과. 이 공유 폴더 단독 검사: **192개 중 186개 통과, 원본 PDF/로컬 런이 필요한 6개 건너뜀**.
- 추가 설계 지침의 성능 향상은 **아직 입증하지 못했습니다**. 단회 비교에서 기본/지침 조건 모두 57통과와 회복시간 미달 1개였습니다.

예전 58통과 기록 일부에는 DC 계산 지점 누락을 놓친 문제가 있었습니다. 이를 고치고 새로 전체 검증한 결과와 구분해야 합니다. [정정 및 현재 결과](docs/RESULTS_AND_LIMITATIONS.md)를 참고하세요.

## 빠르게 확인하기

```powershell
cd EDAI_OpAmp_Rebuild
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```

처음에는 [읽기용 예시](examples/lm358b_25c/README.md)의 사양·PDG·회로·판정 결과를 확인하면 됩니다. 원본 PDF와 실제 런 캐시는 포함하지 않았으므로, 전체 설계 루프 실행에는 [단계별 준비](docs/SETUP_AND_RUN.md)가 필요합니다.

## 폴더

| 위치 | 내용 |
|---|---|
| `opamp_pipeline/` | 각 처리 단계의 핵심 함수 |
| `run_*.py` | 실행 진입점. 우선 `run_verification_pipeline.py`, `run_fixed_harness_loop.py` 확인 |
| `harness/` | 고정 지침과 채택·제외 검토 근거 |
| `manual_inputs/` | LM358B에서 사용한 AI 주석·검토 자료. 새 문서에 무조건 재사용하면 안 됨 |
| `planning_inputs/` | 검토한 프로젝트 범위·온도·목표 선택 정책 |
| `examples/` | 대표 회로와 읽기 전용 결과 요약 |
| `tests/` | 기능·오류 주입 검사와 휴대 가능한 구조 테스트 자료 |
| `legacy_comparison/` | 과거 방식의 호환 진입점. 주 실행 경로 아님 |
| `tools/` | 일회성 이전·검토 보조 도구 |
| `runs/` | 실행하면 생성되는 로컬 기록. Git 제외 |

블록 조합, 조원 UI, 설계 모델 선택·전환, Harness²는 이 작업의 주 실행 경로에 아직 통합하지 않았습니다.
