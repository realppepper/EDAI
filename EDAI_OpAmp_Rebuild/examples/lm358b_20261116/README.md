# 2026-11-16 읽기 전용 설계·검사 예시

같은 LM358B103조건 계획의 folded 기반 회로는74통과/29미검증+기동7/7, 별도 비-folded 회로는 최종71통과/3미달/29미검증+기동7/7이다. 두 결과 모두 제조사 사양 전체 달성/제작 가능한 IC의 증명은 아니다. 설계자 이력과 수정 한도가 달라 토폴로지의 일반적 우열 실험도 아니다.

- `folded_qualified.inc`: 확대 조건을 통과한 folded 기반 DUT.
- `non_folded_latest.inc`:33..38MOS 계열 독립 설계의 최종 채택 비-folded DUT.9/24/36V high 과부하 회복10.933/12.110/12.022µs가10µs 기준 미달.
- `nominal_folded.asc`: 이전 기본 조건/기동 보완 회로의 LTspice 도면이다. 위 확대 조건 회로와 동일한 소자값이라고 해석하지 않는다. DUT만 포함하며 전원/입력/부하/해석은 별도 테스트벤치가 제공한다.
- `engineering_settings_103_cases.json`: 같은 표본/공학적 판정 정책을 새 문서 실행에 선택할 때 쓸 설정. 새 데이터시트에서는 적합성을 검토해야 한다.
- `measurement_plan_readonly.json`: 목표·조건의 출처를 확인하는 원본 계획 사본. 원래 로컬 메타데이터/경로가 있어 바로 재개 가능한 실행 캐시가 아니다.
- `results_summary.json`: 최종 추가2회 결과와 원본 해시. 파형/전체 로그/응답 캐시는 포함하지 않는다.

입력 PDF·페이지 이미지·API 키·실행 환경은 직접 준비한다. 새 실행에는 새 세션을 사용한다. `.inc`는 모델과 FIRSTAMP 서브회로를 담고, 테스트벤치가 include하여 검증한다. 기존 `lm358b_25c` 예시는 이전80조건 시점의 자료로 보존한다.
