# 기동 필수 판정과 현재 모델의 검증 범위

`run_verification_pipeline.py`의 전체 검증은 원문 사양 대장과 별도로 `operational_startup`을 작성한다. 명시된100µs 전원 램프 검사에서 마지막20µs의 내부 노드 변화5mV 이하, 출력의 전원 중간값 오차10mV 이하, 활성 BIAS 상태를 확인한다. 이는 제조사 데이터시트의 기동 사양을 추출한 값이 아니라 프로젝트에서 선택한 동작 전제이다. 모든 전원 인가 파형을 인증하는 의미는 아니다.

검사 계획의 전원별 기동 기록이 필요하며 적격 파형/로그 해시를 확인한다. 미통과/누락은 회로 설계 요청에 전달되고 구현 범위의 완료를 막는다. 기동 게이트는 원문 사양 조건 수에 더하지 않는다. 목표58조건이 통과해도 기동이 미통과면 완료가 아니다. 후보 선택에서는 기존 통과 기동의 회귀를 허용하지 않는다.

현재22개 미검증 조건은 누설/불균형/잡음 모델, 입력 임피던스 전체 해석, 두 번째 채널과 결합 경로, 측정 어댑터의 한계로 남는다. 모델 변경 없이 THD+N의 결정론적 왜곡 부분은 추가 측정하지만 잡음까지 검증한 것으로 취급하지 않는다. 용량 성분만 측정해 전체 입력 임피던스 통과로 바꾸거나, 이상적 채널 복제로 분리도 통과를 만들어내지 않는다.

```powershell
python run_model_capability_audit.py --netlist <회로.inc> --plan <plan_02_measurements.json> --ledger <같은회로의LEDGER.json> --output-dir <새폴더> --ltspice <LTspice.exe>
```

왜곡 측정은 실제 시간 파형의 기본파/고조파를 적합하고, 해상도·정상상태·진폭·부하 전류·두 시간 간격의 일치를 확인한다. 알려진 선형/왜곡 기준 회로를 먼저 측정한다. 원래 사양 대장은 변경하지 않고 별도 부분 증거를 저장한다. `noise_included=false`, `thdn_compliance_established=false`를 유지한다.

새 프로젝트 조건은 원문 HKG/PDG를 고치지 않고 별도 프로젝트 정책과 계획으로 생성한다. 전원 표본 수가 달라지면 전체/지원/미검증 조건 수가 함께 달라질 수 있다. 서로 다른 조건 수의 단순 통과 수를 하네스 성능 비교로 사용하지 않는다.
