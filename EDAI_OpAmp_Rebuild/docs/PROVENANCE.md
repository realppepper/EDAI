# 출처와 공유 범위

## 참고한 구현

- 조원 [AnalogVerifier](https://github.com/eethsc/analogverifier): 사양/검사/피드백 개발 흐름과 하네스 구성 아이디어를 검토했습니다. 그대로 전체 복제한 서비스가 아니라 단계별 독립 재구성입니다.
- `harness/`는 기본 지침·경험 내용을 검토한 채택/수정/제외 근거를 보존합니다. C1~C8 이름과 실제 활성 지침을 구분합니다.
- IEEE 메타데이터 MCP는 조원 어댑터를 참고해 독립적으로 구성했습니다. 논문 제목/초록 검색 범위이고 전문 전체나 회로 식의 검증을 보장하지 않습니다.
- LTspice 측정 근거는 해당 검증 코드의 `SOURCE`, 주석과 기준 회로에 남아 있습니다. 일반 MOS 계수와 기준 회로의 이상 모델을 구분합니다.

## 데이터시트

TI LM358 계열 데이터시트에서 LM358B를 대상으로 사용했습니다. 원래 입력은 `lm358.pdf`, SHA256 `95fd2cc9c87014b32c2939009266e2c5938fc3c11a61d52015fa53fdeef5ab70`입니다. 공개 문서가 개정되면 새 파일과 예제의 행 ID가 달라질 수 있습니다. 원본 PDF·페이지 이미지·전체 API 응답은 이 브랜치에 포함하지 않았습니다.

## 포함한 것

- 핵심 Python 모듈·실행 진입점·테스트·최신 검토 파일과 프로젝트 정책.
- 고정 하네스와 검토 근거.
- 테스트에 필요한 HKG/PDG 구조 사본. 로컬 실행 메타데이터/개인 경로를 제거하고 테스트 정책의 지문만 해당 사본에 다시 연결했습니다. 사양·원문 ID·관계·조건 값은 유지했습니다.
- 대표 사양·PDG·회로·80조건 결과의 읽기 전용 요약. 결과를 더 좋게 바꾸거나 미검증을 통과로 바꾸지 않았습니다.

## 제외한 것

- `.env`, 실제 API 키, 개인 Python 환경, 패키지 캐시, 실행 프로그램.
- 약3.3GB의 원래 `runs/` 파형·로그·그림·과거 체크포인트와 반복 코드 스냅샷.
- 개인 누적 채팅/중단 메모와 과거 실행 결과 전체. 현재 공유 설명은 이 문서 묶음으로 다시 정리했습니다.

기존 원본 작업 폴더를 수정하거나 지운 것이 아니라 별도 브랜치 작업 공간에 공유본을 만들었습니다. 런타임 Python 코드는 원본에서 복사했으며, 로컬 런 없이 테스트할 수 있도록 두 테스트의 자료 탐색에 고정 fixture fallback을 추가했습니다. 이는 설계·측정 알고리즘의 변경이 아닙니다.

보조 위상여유 보고서의 개인 설치 경로 표기1개를 일반적인 설치 위치 안내로 바꿨습니다. 수치 계산·모델·판정 알고리즘은 변경하지 않았습니다.
