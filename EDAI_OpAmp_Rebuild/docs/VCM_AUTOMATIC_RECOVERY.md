# 입력 범위 측정 누락의 제한된 자동 복구

2026-11-15. VCM DC 검사에서 일부 지점이 빠졌을 때 사용하는 복구 경로를 추가했다. 회로·모델·원래 시험 범위·지점 수·판정 기준은 유지한다.

## 실행 순서와 정지 기준

1. 기존 중심→양끝 검사를 수행한다. 완전한 측정이면 그대로 판정한다.
2. 기존 수치 실패/누락 처리에 따라 전체 상승 스윕을 수행한다.
3. 전체 상승 스윕에서도 요청 지점이 누락된 경우에만, 초기 추정값을 제거하고 Normal 계산기로 **한 번** 더 실행한다. 이 실행에는 기존 일반 solver 재시도를 중첩하지 않는다.
4. 모든 지점을 측정한 뒤 기존 성능 기준으로 판정한다. 측정에 성공했더라도 성능이 미달하면 실패다. 복구 실행도 시간 초과·누락 등으로 실패하면 `execution_error`로 남기고 추가 반복하지 않는다.

정상적으로 측정한 성능 미달, 잘못된 지점 좌표·역방향 축·입력 스키마 오류는 새 복구의 조건이 아니다. 새 경로는 VCM DC에만 적용하며 다른 분석이나 기준 회로에는 적용하지 않는다.

기존 두 전략에 더한 새 수치 복구 기회가 한 번이라는 뜻이다. 전체 검사에서 기존에 존재하던 실행 재시도까지 모두 합쳐 한 번이라는 뜻은 아니다. 성공·실패 이력과 누락 좌표를 `numerical_attempts`에 보존한다.

## 코드

- `opamp_pipeline/verify_04_dc_coverage.py`: 복구 조건과 횟수 제어, 초기 추정값 제거 및 Normal 설정 생성. 빈 옵션 줄과 마지막 줄바꿈도 정규화한다.
- `run_extended_verification.py`: 새 계산 경로를 실제 실행기에 연결했다. 시동 초기 추정값을 다시 주입하지 않으며 추가 실행을 한 번으로 제한한다. 실제 로그의 계산기가 Normal인지 확인한다. 불완전한 실행을 회로의 물리적 실패로 확정하지 않는다.
- `tests/test_dc_coverage.py`: 누락 후 복구, 실패 후 종료, 정상적인 성능 미달의 재시도 금지, 비정상 좌표 거부, 시험 조건 보존 등을 검사한다.

계산기 옵션은 ADI 공식 문서의 `solver=norm` 표기를 사용한다. [공식 시뮬레이션 명령 참조](https://github.com/analogdevicesinc/ltspice-reference/blob/main/ai_ref/SIMULATION-COMMANDS-REFERENCE.md).

## 검증 결과와 한계

전체 자동 검사 **209개 통과**.

실제 저장된 15V 중심 스윕의 누락과 전체 상승 스윕의193/201점 결과를 현재 완전성 검사로 다시 읽은 뒤, 새 정책을 통해 실제 LTspice Normal 복구를 한 번 실행했다. 측정과 최종 VCM 판정에는 본래 `measure`와 `case_verdict`를 사용했다.

| 후보 | 새 복구 실행 수 | 결과 |
|---|---:|---|
| 30pF·소자 축소 | 1 | 201점 모두 측정, 최대 추종 오차3.981mV≤10mV, 해당VCM 조건 통과 |
| 27pF | 1 | 60초 시간 초과, 미판정으로 종료 |

이전 수동 진단에서 통과했던27pF도 이번 제한 시간 내 계산을 완료하지 못했다. 자동 복구가 항상 성공하는 것은 아니다. 결과를 합격으로 바꾸기 위해 반복 실행하지 않았다.

이 검증은 **정책 함수·저장된 실제 실패 데이터·실제 계산기·본래 측정/판정 함수를 연결한 제한된 통합 검사**다. 전체 CLI 또는 전체 설계 루프의 완주를 검증한 것은 아니다. 전체 CLI 재실행은 관련 없는5V 시동/동작점 계산의 시간 초과 때문에 중단했고, `core_27p/INTERRUPTED.json`에 구분해 남겼다.

초기 구현에서는 계산기 지정값을 `normal`로 사용했다가 공식 표기인 `norm`으로 정정했다. 빈 옵션 줄과 줄바꿈도 정리했다. 정정 전 시간 초과 기록은 삭제하지 않았다. 모든 시간 초과의 원인이 이 표기 때문이라고 확정하지 않는다.

최종 검증 결과는 `runs/diagnostics/20261115_vcm_auto_recovery/final_norm/TARGETED_RESULTS.json`과 각 후보의 `CHECKS.json`, `VERDICT.json`, 실제 `.cir/.raw/.log`에 있다. 이전 중단·검증 실패는 상위 폴더에 보존했다.

## 적용 범위

이후 새 실행부터 적용한다. 기존 비교 대장·점수·회로를 덮어쓰지 않았다. 이전 코드로 동결한 세션은 코드 서명이 달라졌으므로 새 실행을 만들어야 한다. 미검증22개, 다른 성능 미달, Harness², 모델 전환은 변경하지 않았다. Git push는 하지 않았다.
