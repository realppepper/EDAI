# PDG 기능 보강 결과

원본 조원 코드의 PDG 감사·관계 출처·시간표 생성·시각화를 검토하고 현재 데이터 모델에 맞게 보강했습니다. 원본 명시 관계와 공학적 해석을 구분하고 출처 없는 지연을 데이터시트 값으로 표시하지 않습니다.

- 채널별 입력-출력 경로: 4/4.
- 교차 채널 신호 연결: 0개 오류.
- 전원에서 출력으로 도달하지 못하는 경우: 0개.
- 원문 명시 관계 4개, 공학적 해석 관계 8개. 정확도 점수로 해석하지 않습니다.
- 지연 수치 미정 12개. 실제 실행 정책이 없어 기본 시각을 채우지 않았습니다.

`pdg_03_audit.py`는 고립 포트·필수 입력 경로 누락·교차 채널·조건 경로 누락·전원 경로 누락을 검출합니다. 실패하면 정책 생성과 완료 게시를 중단합니다. 이는 원문의 모든 의미를 독립적으로 검증하는 감사는 아닙니다.

`pdg_04_schedule.py`는 DC 동작점/AC 분석의 작업 순서와 과도응답 이벤트 시각을 구분합니다. 명시적 정책의 시간과 출처·이유만 사용하고 자동 지연 추정은 하지 않습니다. 형식이 맞는 정책도 실제 DUT 회로·포트 바인딩·동작 조건 유효성 게이트를 실행한 것은 아니므로 실행 준비 완료로 승격하지 않습니다. 현재 저장 실행은 정책 입력 대기입니다.

`pdg_05_visualize.py`는 관계, 출처, 원문 인용 및 분석별 실행 방식과 미정 항목을 보여주는 로컬 검토 화면을 생성합니다. 화살표는 기능 관계이며 활성화 시각의 선후가 아닙니다. 외부 API/CDN을 사용하지 않습니다.

시험: 전체68개 통과. 누락/교차 연결/전원 단절을 넣어 감사가 거부하는지 확인했고, 기본 정책 없음·DC/AC 시간표 혼용 거부·명시적 과도응답 정책·NaN/음수/잘못된 시각/게이트/포트 역할 거부를 검사했습니다. 테스트용 과도응답 시각은 실제 LM358B 권장 정책으로 채택하지 않았습니다. 사용자 입력의 script 종료 문자열을 안전하게 포함하는지도 검사했습니다.

뷰어의 JS 구문과 SVG 렌더는 확인했습니다. 실제 Edge 자동 조작 시험은 브라우저 시작 단계에서 TargetClosed/파이프 오류로 완료하지 못했습니다. 따라서 브라우저에서 클릭/필터를 실제 조작해 통과했다고 주장하지 않습니다. 재시험 도구는 `tools/verify_pdg_viewer.cjs`입니다.
