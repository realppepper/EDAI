# 추가 검사와 모델 한계 분류

`run_additional_adapter_checks.py`는 완료된 회로의 동결 상태·원문 계획·기존 판정을 덮어쓰지 않고, 추가로 검토한 조건을 별도 결과 폴더에서 검사한다. DUT를 변경하거나 회로 수정 횟수를 소비하지 않는다.

```powershell
python run_additional_adapter_checks.py --netlist <기존 최종.inc> --request <ADDITIONAL_REQUEST.json> --output-dir <새 결과 폴더> --ltspice <LTspice.exe>
```

입력 요청은 PDF/회로 SHA256, 명시적인 정착시간 fixture·오차율·스텝·시간 기준, 소스 행 참조, 물리 채널 수와 모델 기능 선언을 담는다. 모델 기능은 회로의 성능 판정과 별개다. `unverified_model`과 `not_applicable`은 통과가 아니다. 모델 기능이 있다고 선언해도 미구현 어댑터가 자동 승인되지는 않는다.

- 정착시간 fixture는 계획의 `input_step_V`, `error_percent`, `baseline_fraction_of_supply`를 사용한다. 입력 변화가 끝난 뒤 마지막 오차대 진입과 관찰 종료까지의 체류를 측정한다. 양 방향 일차계 기준 회로를 해석적 램프 응답과 대조하고, 빠른/느린 제어가 각각 목표 통과/실패로 분리돼야 한다.
- 저항 단독 검사는 공통모드 DC 전압 변화와 각 입력 전류의 기울기로 정의한다. R||C를 강제하지 않는다. 1TΩ,0.25TΩ,개방 기준 회로를 사용한다. 분해능 이하 전류를 무한 저항 또는 통과로 치환하지 않는다. 고정 LEVEL1의 누설이 검증되지 않은 DUT 결과는 모델 미검증이다.
- 모델 기능 분류는 입력 누설, 전체 전압 잡음, 입력 전류 잡음, RF 정류를 구분한다. THD+N에는 잡음 모델 외에 적분 대역과 별도 검증 어댑터도 필요하다. 단일 채널의 채널 분리는 비적용이다.
- 조건 검증은 전기적 표의 다음 페이지에 있는 Full range 각주도 살펴 명시적인 제품/등급별 온도 범위를 대조한다. 원문에 없는 범위를 추정하거나 알 수 없는 제품에 C 등급을 일괄 적용하지 않는다. 여러 등급이 함께 있는 행은 범위별 적용 검토를 유지한다.

기존 성공은 당시 검사 범위의 역사적 결과다. 새 정착시간 조건에서 미달하면 추가 범위의 실패를 그대로 기록하며, 기존 성공에 합쳐 전체 성공으로 표시하지 않는다. 코드 변경 전의 파일과 해시는 원 세션의 `followup_20261117/pre_change_code`에 보존돼 있다. 동결 코드 해시를 현재 코드로 갱신해 기존 세션 재개 검사를 우회하지 않는다.
