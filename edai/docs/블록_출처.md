# 구조 블록 모음의 출처

`structure_blocks.py` 의 블록(입력단·출력단·보상)이 어떤 공개 논문의 구조와 같은지 정리한 표입니다.

## 이 문서를 만든 방법

1. 블록은 2026-11-23(AB급 출력단은 11-28)에 Claude Code 가 일반 지식으로 작성했습니다. 작성할 때 참고한 원본은 없습니다.
2. 2026-11-28 에 IEEE Xplore API 로 같은 구조를 다룬 논문을 찾아 출처로 연결했습니다. 검색어에는 구조 이름만 넣었습니다.
3. 아래 "초록 근거"는 IEEE Xplore API 가 돌려준 초록에서 그대로 옮긴 문장입니다.
4. "일치 정도"는 이렇게 나눴습니다.
   - **초록으로 확인**: 블록의 구조가 초록에 직접 적혀 있음
   - **본문 확인 필요**: 널리 그 구조의 출처로 인용되지만, 초록에는 구조 이름이 없음. 본문 그림을 봐야 확정할 수 있음

## 검증하는 방법

1. 각 줄의 DOI 링크(https://doi.org/...)를 열면 IEEE Xplore 논문 페이지로 갑니다.
2. 초록이 아래 "초록 근거"와 같은지 확인합니다.
3. "본문 확인 필요"인 줄은 학교 IEEE 구독으로 PDF 를 열어 해당 구조 그림이 있는지 봅니다. 그림 번호를 확인하면 이 표의 "확인 결과" 칸에 적어 주세요.

## 주의

- 저자, 권·호·쪽, 연도는 IEEE Xplore API 결과에서 옮겼습니다.
- 위 논문들은 그 구조를 처음 제안했다는 뜻이 아니라, 그 구조를 다룬 대표적인 IEEE 논문이라는 뜻입니다. "처음 제안"으로 쓰려면 본문과 인용 관계를 따로 확인해야 합니다.
- 상보 뒤집기(NMOS↔PMOS), 캐스코드 추가, 바이어스 회로(beta multiplier)는 블록 모음이 아니라 다른 파일(`complement.py`, `cascode.py`, `bias_reference.py`)이라 이 표에 넣지 않았습니다.
